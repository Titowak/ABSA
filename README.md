Multilingual Aspect-Based Sentiment Analysis (Farsi & English)
A comprehensive framework for fine-grained sentiment analysis across Farsi (Persian) and English languages. This repository implements state-of-the-art models to detect aspects within text and classify the author's sentiment toward each specific aspect at the sentence level.

🎯 Key Features
Bilingual Processing: Simultaneous support for Farsi (Persian) and English languages

Aspect Detection: Identifies specific aspects/targets within text (e.g., "battery life", "customer service")

Sentiment Classification: Determines author's opinion toward each aspect (Positive, Negative, Neutral)

Sentence-Level Analysis: Processes individual sentences for precise aspect-sentiment mapping

Unified Framework: Consistent architecture for both languages with language-specific optimizations
